# Social Media Analytics & QA Testing

## Project Overview
A Python-based command-line application developed to analyze social media engagement data and perform manual functional testing. The tool calculates engagement metrics, identifies user statistics, searches records, and generates visualizations to help understand social media performance.

## Features
- Calculates total likes, comments, and shares.
- Identifies users with the highest and lowest likes.
- Calculates average likes.
- Searches for individual users and displays their records.
- Generates individual, overall, and combined engagement graphs.
- Handles invalid menu choices and user search inputs.
- Provides a menu-driven command-line interface.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## QA Testing
Manual functional testing was performed to verify the application's main features and expected behavior.

- Created and documented 10 test cases.
- Tested engagement metric calculations and user statistics.
- Tested existing and non-existing user searches.
- Verified invalid menu input handling and application exit functionality.
- Documented test results and testing summary.

## Testing Documentation
- `test-cases.md` — Detailed test cases and expected/actual results.
- `test-summary.md` — Testing overview, results, scope, and limitations.

## Project Structure
- `main.py` — Main application.
- `num.py` — Supporting Python script.
- `sma.csv` — Social media dataset.
- Graph image files — Generated data visualizations.
- `test-cases.md` — Manual QA test cases.
- `test-summary.md` — QA testing summary.

## Testing Scope
Testing was performed manually using the available dataset and selected inputs. Automated testing has not been implemented.

## Key Learning
This project provided practical experience in Python-based data analysis, data visualization, command-line application behavior, test case design, and manual functional testing.
